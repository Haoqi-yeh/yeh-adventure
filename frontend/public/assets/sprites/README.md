This folder is reserved for character and prop assets generated through the sprite pipeline.

Recommended layout:

- `player/`: controllable protagonist sheets
- `npc/`: recurring NPC sheets
- `portraits/`: dialogue portraits or busts
- `props/`: signs, rocks, flowers, route objects
- `fx/`: spell or interaction effects

Use the presets defined in `src/lib/assets/game-art.ts` as the first-pass output contract.
